# orca-pod-form

`orca-pod-form` повторно открывает существующую форму настроек Orca Pod в проекте, где полный setup уже выполнен. Скилл сохраняет выбранные профили без повторной настройки зависимостей, graphify или памяти. [Назад к orca-pod](../../README.ru.md) · [Инструкция скилла](SKILL.md).

| Агент | Вызов |
| --- | --- |
| Claude Code | `/orca-pod-form` |
| Codex | `$orca-pod-form` |
| Pi | `/skill:orca-pod-form` |
| Qoder | `/orca-pod-form` |
| OMP | `/skill:orca-pod-form` |

Форма по-прежнему обнаруживает каталоги моделей. Отмена не меняет проект; если конфигурация изменилась, пока форма была открыта, скилл откажется её перезаписывать. Существующие комментарии YAML при сохранении не сохраняются. Если конфиг отсутствует или ещё не перенесён из старого расположения, сначала нужен `orca-pod-setup`. Установка OMP и ограничения sandbox описаны в [главном README](../../README.ru.md).

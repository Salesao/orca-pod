Pipeline role setup

The pipeline splits a task between four roles in separate Orca terminals: Planner writes the plan, Implementer carries it out, Reviewer and Chief Reviewer check the result independently. Here you pick an agent and a model for each role by strength and price, plus the subagents the role hands work to in parallel.

Settings will be saved to orca-pod.yaml — the agent writes the file after validation.

    Language

    One language per project, for all profiles: the roles talk to you in it in their terminals. “Auto” follows the language of your message, or English when there is no text. Other tags (for example pt-BR) are set by editing the YAML and are kept by the form.

    Profiles

    A profile is its own set of agents, models and limits, for example “fast” and “high quality”. A new profile is created as a copy of the current one. If there are several profiles, the Coordinator asks which one to use before launching.

    Where the models come from

      Profile

      Letters, digits, “.”, “_” or “-”, no spaces, up to 64 characters.

      How many subagents one role runs at the same time: from 1 to 100, 6 by default. This is not a counter: more can run in total during a run.
      Full access full_access
